# kavia.ai User Guide – Simple Steps to Get Started

---

## Introduction

Welcome to **kavia.ai**! This platform lets you automate software development tasks using specialized AI agents. This guide offers a clear, step-by-step walkthrough for new users: from signing in to submitting tasks, choosing agents, handling files, and collecting your outputs. All instructions are given in simple language, with notes on what to click and where to find each feature.

---

## 1. Logging In

1. Go to the kavia.ai website in your browser.
2. Enter your username and password, then click **Login**.

## 2. Navigating the Dashboard

After logging in, you will land on the **Dashboard**. The main interface sections are:

- **Sidebar/Navigation Panel** (left): Access main areas such as Tasks, Agents, Files, and Outputs.
- **Main Panel** (center): Displays your current content (task list, agent selection, file uploads, outputs).
- **Header/Top Bar**: Shows your profile, notifications, and settings.

## 3. Submitting a Task

To have the agents help you (for example, write code, fix bugs, generate documentation), follow these steps:

1. Click the **Tasks** section in the sidebar.
2. Press the **New Task** or **+ Add Task** button.
3. In the form:
    - Enter a clear, specific description of what you want (e.g., “Implement user login API with FastAPI”).
    - Optionally, add related files, input data, or context.
4. Choose the **task type** if prompted (coding, testing, documentation, bug fix, etc.).
5. Click **Submit**.

## 4. Selecting or Assigning Agents

If kavia.ai asks you to pick or assign an agent:

1. In the Task’s detail view, find the **Agent** dropdown or “Assign Agent” button.
2. Review the list of agents:
    - **PlanningAgent** – for roadmaps, structure design
    - **CodeWritingAgent** – for writing/refactoring code
    - **TestCodeWritingAgent** – for creating test code
    - **TestExecutionAgent** – for running tests
    - **BugFixingAndVerificationAgent** – for fixing/verifying bugs
    - **DocumentationAgent** – for updating or creating docs
    - ...and more as listed in the cheat sheet below.
3. Select the most appropriate agent for your task.
4. Click **Assign** or **Start**.

## 5. Uploading and Viewing Files

- To **upload files** (code, documents, assets):
    1. Go to the **Files** tab or section.
    2. Click **Upload File**.
    3. Choose your file(s) and press **Open/Upload**.
  
- To **view or download files**:
    1. Open the Files section from the sidebar.
    2. Click on any file to preview or select **Download** to save locally.

## 6. Monitoring Outputs and Results

Once a task is submitted:

1. Go to the **Outputs** (or **Results**, or directly the task in Tasks) section.
2. Select your task – you’ll see status (e.g., “In Progress,” “Completed”), agent actions, and logs.
3. For code or documents, download the results using the provided button.
4. You can also review process logs and, for multi-step tasks, watch the step-by-step agent process in real-time.

Tips:
- Use the “Refresh” button to update the task list or outputs.
- Status indicators (colored tags or icons) help you track what’s done or still running.

## 7. Tips & Best Practices

- **Be Specific**: The more detail you give in your task description, the better the results.
- **Choose the Right Agent**: Refer to the agent cheat sheet for which agent does what.
- **Check Logs**: Review output logs for progress, errors, or suggestions from the agents.
- **Documentation**: Use the DocumentationAgent if you want up-to-date guides or architecture docs alongside the code.
- **Help**: If you’re stuck, use the HelpAgent or check the Help section from the navigation bar.

## 9. Getting Your Desired Output

- **Code**: Submit a code writing or bug fixing task, download when ready.
- **Documentation**: Assign DocumentationAgent, find docs in Files/Outputs.
- **Test Results**: Submit testing task, review logs and status in Outputs.
- **Architecture/Diagrams**: Request in your task, DocumentationAgent will provide.

---

## 10. Example Workflow (Putting It All Together)

**To create an API endpoint:**

1. Click Tasks → New Task.
2. Enter: “Create `/leave-request/submit` POST endpoint in FastAPI backend.”
3. Attach any relevant files if needed.
4. Assign to CodeWritingAgent.
5. Monitor progress via Outputs.
6. Download or review generated code in Files.

---

## 11. Common Issues and Troubleshooting

- **My task is stuck or slow:** Try refreshing, checking agent logs, or restarting assignment.
- **Error or failure in output:** Read logs for cause; try a new, clearer prompt or reassign to another agent.
- **Need explanation or help?** Use HelpAgent or consult documentation.
